## 2. 桌面小组件（已完成）

小组件已在真机上拖到桌面确认过外观，截图收在 `docs/screenshots/widget.png`，README 里也引用了。
过程中还修掉一个缺陷：记录增删改之后小组件不会立即刷新，现在数据一变就重画
（规则在 `widget/WidgetRefreshRules.kt`，只认「最近一条是否变化」，避免无谓刷新）。

## 3. 界面打磨（已做一轮，仍可继续）

界面已经按《产品设计文档》第 5 节重做过：顶栏、列表、表单都换成了图标，
列表页改成单卡片 + 底部胶囊工具栏，详情页／编辑页／导出页统一了配色、圆角与层级。
还能继续打磨的点：

- 通知栏图标仍沿用临时画的形状（见第 1 节）。
- 深色模式已跟随系统，但没有在真机上仔细看过实际效果。

## 4. 提醒开关的设置入口

提醒开关在代码里已经存在（`Preferences.reminderEnabled`），但**界面上没有入口**，
用户目前无法自己关掉每月提醒。产品设计里写的「用户可以点击关闭」只做到了通知本身可划掉。

建议在导出页或新增的设置页里加一个开关。

## 5. 正式签名与发布包（已完成）

已经建好正式签名并配好发布构建：

- 正式签名：`keystore/release.jks`，口令在 `keystore/release.properties`，
  这两个文件都在 `.gitignore` 里，**不入库**（说明见 `keystore/README.md`）。
- 打包：`gradlew.bat :app:assembleRelease`，产物在 `app/build/outputs/apk/release/app-release.apk`。
- 手机上装的和 GitHub Release 上发布的都是正式签名包（当前版本 0.2.2），
  所以老版本可以直接覆盖升级、记录不丢。
- 注意：正式包与调试包签名不同，**不能互相覆盖安装**，切换前先用「导出备份」留底。
- 再提醒一次：签名密钥务必另行备份（已经存了一份到「文档\工作快录-签名备份」），
  丢了就再也无法给已发布的版本发更新。
