# 工作快录 — 待办事项

记录时间：2026-09-17

第一版功能已经全部实现并在真机（荣耀 400 Pro / Android 16）上验证通过，可以日常使用。
本文列出下一次需要继续做的内容，按优先级排列。

## 1. 应用图标（下次优先）

当前应用**没有设置图标**，桌面上显示的是安卓默认图标。

要做的事：

- 绘制或选定一个图标，主题建议延续现有主色（#136A52）与「记录」的意象。
- 生成自适应图标所需的各尺寸资源，放入 `app/src/main/res/mipmap-*`。
- 在 `AndroidManifest.xml` 的 `<application>` 上补 `android:icon` 与 `android:roundIcon`。
- 同时替换通知用的白色单色图标（现在是 `res/drawable/ic_notification.xml` 里临时画的文档形状）。
- 图标属于应用身份的一部分，装上后再改需要卸载重装，建议这一次做扎实。

## 2. 桌面小组件外观验证

小组件已经注册并能刷新，但**外观没有验证过**——放置小组件必须手动拖拽，命令行做不到。

要做的事：长按桌面空白处 → 添加小组件 → 找到「工作快录」→ 拖到桌面，
确认显示「X 天未导出」与上次导出日期，颜色和留白是否满意。

## 3. 界面打磨

界面目前功能完整但偏朴素，与《产品设计文档》第 5 节的规范还有差距：

- 顶栏、列表、表单里该用图标的地方目前用的是文字（例如返回、导出、加号）。
- 空列表的提示文字位于屏幕正中，位置偏低，可以上移贴近内容区。
- 列表卡片、输入框的圆角与投影还没有完全对齐规范里的数值。
- 深色模式已跟随系统，但没有在真机上检查过实际效果。

## 4. 提醒开关的设置入口

提醒开关在代码里已经存在（`Preferences.reminderEnabled`），但**界面上没有入口**，
用户目前无法自己关掉每月提醒。产品设计里写的「用户可以点击关闭」只做到了通知本身可划掉。

建议在导出页或新增的设置页里加一个开关。

## 5. 正式签名与发布包

现在手机上装的是**调试版**（debug），用调试签名，体积和速度都不是最优。

如果打算长期自用或分发给同事，需要：

- 生成正式签名密钥并妥善保管（丢失后无法覆盖升级）。
- 配置 `release` 构建，打出正式包。
- 注意：正式包与调试包签名不同，**不能覆盖安装**，切换时现有记录会丢失，
  切换前务必用「导出备份」存一份。
