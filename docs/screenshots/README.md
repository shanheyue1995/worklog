# 截图放这里

README 会引用这个目录下的图片。建议放这几张（横竖都行，宽度 1000px 左右就够）：

| 文件名 | 内容 |
| --- | --- |
| `list.png` | 记录列表（含底部搜索／新建／导出工具栏） |
| `edit.png` | 新建记录页 |
| `export.png` | 导出页的逐页预览 |
| `widget.png` | 桌面小组件 |

两点注意：

- **用假数据截图**。地点、问题描述、照片都不要用真实的学校和设备（照片里可能有教室、办公室环境）。
  可以新建几条"高一(3)班 投影仪没信号"这样的示例记录，截完再删掉。
- 截完把图发到仓库里，再到 README 的「截图」一节把注释换成图片引用：

```markdown
![记录列表](docs/screenshots/list.png)
```
