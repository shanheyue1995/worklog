# 截图

README 引用了这个目录下的图片，目前这些是荣耀 400 Pro（Android 16）上的实机截图，
数据全是编的（假地点、假描述、合成的示意图）。

| 文件名 | 内容 | 状态 |
| --- | --- | --- |
| `list.png` | 记录列表 | 已有 |
| `detail.png` | 记录详情（带照片） | 已有 |
| `edit.png` | 编辑记录 | 已有 |
| `export.png` | 导出页的逐页预览 | 已有 |
| `widget.png` | 桌面小组件 | **缺**，需要手动拖到桌面后截一张 |

## 换图时注意

- **只用假数据**。地点、问题描述、照片都不要用真实的学校和设备（照片里会出现教室、办公室环境，
  画面上还可能带上同事的名字）。
- 截图尺寸建议保持手机原始分辨率，宽度 1000～1300px 在 README 里显示最合适。
- 换完图不用改 README，文件名一样就行。
