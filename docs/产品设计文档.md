# 工作快速记录 — 产品设计文档

版本 v0.2 ｜ 2026-09-16 ｜ 状态：MVP 方向与界面样式已确认

## 1. 背景与问题

目标用户是中小学里负责维护电子教学设备的老师，日常接触的多媒体教室、班班通、投影、电子白板、功放、教学电脑等设备，出故障、换耗材、做巡检都需要留痕。

他们的记录过程在三个环节上都不顺：

- **采集慢**：现场手里拿着工具，很难停下来打字。
- **整理累**：月底或期末要交台账，零散记录得重新抄一遍。
- **没动力**：不记也不影响当下干活，但考核、工作量证明的时候又需要。

现有的替代方案（微信收藏、手机备忘录、纸质本子）能记下来，却交付不了——这些记录最后要变成一份能给领导看的材料。

## 2. 产品定位

一句话：让设备维护老师在手机上十秒记一条，月底一键导出成能直接交上去的工作台账。

核心判断是，这个产品的差异化不在"能记录"，而在"能交付"。会打字、能录音的工具到处都是，缺的是从零散记录到正式台账这一段。所以第一版的重心是导出的形态，而不是功能的多少。

## 3. 核心使用场景

**场景 A｜现场即记**：修完投影，掏手机，从快捷入口直达新建，地点一点即填，语音说一段，顺手拍两张照，保存。目标十秒内完成。

**场景 B｜事后补录**：当天忙忘了，晚上翻着相册补记，时间需要能手动改。

**场景 C｜月度交付**：月末收到提醒，选本月范围，导出 PDF 报告，打印或发微信给领导。

**场景 D｜回查历史**：搜索或翻列表，确认"这间教室上次修的是什么问题"。

## 4. MVP 功能范围

### 4.1 一条记录包含什么

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 时间 | 是 | 年月日时分。新建时自动填当前时间，可手动修改以支持补录 |
| 地点 | 是 | 文本输入，自动补全历史地点，常用地点置顶 |
| 问题与解决方法 | 是 | 一段自由文本，支持语音输入 |
| 照片 | 否 | 1–9 张，调用系统相机拍摄或从相册选择 |

设计原则：必填项越少越好。地点是唯一需要高频重复输入的字段，必须做到一点就选，否则"十秒记一条"不成立。"问题与解决方法"保持一段自由文本，不做拆分，因为第一版不做分类统计，拆开只会增加输入负担。

### 4.2 功能清单

**记录**

- 新建记录，桌面快捷入口可直达
- 语音输入转文字，复用系统或第三方输入法的语音能力
- 调用系统相机拍摄或从相册选择照片，支持多张
- 编辑、删除记录
- 记录列表按时间倒序，带照片缩略图
- 搜索地点与内容关键词

**导出**

- 选择时间范围，导出 PDF 格式的图文报告
- 报告中的照片嵌入文件本体，不引用原图路径，避免用户清理相册后报告出现空白
- 报告内容为：标题、时间范围，以及逐条记录（时间、地点、问题与解决方法、照片）
- 不含抬头与签名
- 照片统一压缩后写入报告，控制文件体积，保证能通过微信发送
- 全部数据导出，作为备份，包含原始照片

**提醒**

| 层级 | 形式 | 触发方式 |
| --- | --- | --- |
| 第一层 | 打开 App 时的顶部提示条，可就地导出 | 距上次导出超过阈值 |
| 第二层 | 桌面小组件，显示上次导出时间，超期变色或加提示文字 | 持续显示 |
| 第三层 | 通知 | 每月 1 号提醒一次，用户可关闭 |

第三层选择按日历触发而非按累计天数触发，是因为老师交台账本来就是按月交的，按月份提醒更贴合真实节奏，也更容易被接受。第三层在国产手机上可能被系统延迟，第一层的提示条是可靠兜底。

### 4.3 明确不做

- 账号、登录、云同步、多人协作
- 工单派发、审批流
- 统计图表、故障分类、绩效指标
- 设备资产档案、耗材库存管理
- 桌面图标按时间变色（评估结论：国产手机桌面对动态图标支持不稳定，容易导致图标丢失；颜色本身缺少语义；红绿渐变对色盲用户不成立）
- 报告导出为长图（评估结论：微信会压缩超长图片导致文字模糊，且更适合微信阅读的形态是分段出图，规则复杂）
- App 内相机连拍（评估结论：需要自建拍照界面并处理相机兼容，开发量明显大于收益）
- iOS 版本

## 5. 界面设计规范

界面整体走安卓原生 Material 3 的设计语言：大标题顶栏、填充式输入框、分段按钮、扩展式悬浮按钮，用圆角和投影表达层级，而不是靠描边分隔。

参照的成熟产品形态：

- 列表页参考笔记类应用（Google Keep、小米笔记）的卡片写法：左侧照片缩略图，右侧地点、时间与摘要。
- 提醒面板参考 Android 13 的通知卡片：带应用图标、时间与关闭按钮。
- 报告预览参考文档查看器：灰底衬白纸。
- 桌面小组件参考日历与待办类应用的写法：数字放大做主视觉，超期用彩色圆点标记。

### 5.1 颜色

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主色 | #136A52 | #5FD3AA |
| 主色容器 | #D3EEE4 | #16362C |
| 警示色 / 容器 | #9A5B0A / #FDF0DC | #EAB268 / #382A13 |
| 危险色 | #B3261E | #F09A94 |
| 页面背景 | #F3F6F5 | #0E1110 |
| 卡片表面 | #FFFFFF | #191D1C |
| 次级表面 | #EAEFF0 | #222726 |
| 正文 / 次要文字 | #151918 / #6A746F | #EAEFED / #9AA5A0 |

全部颜色成对定义，深色模式自动跟随系统，不做单独的开关。

### 5.2 形状与层级

- 记录卡片圆角 18，输入框 14，按钮为胶囊形，悬浮按钮 18，手机屏幕 30。
- 卡片不使用描边，靠两层微投影表达层级：一层 1px 贴边阴影加一层大范围柔和阴影。
- 图标统一为线性图标，默认 18px、1.8px 描边，继承文字颜色。

### 5.3 文字层级

| 层级 | 字号 |
| --- | --- |
| 页面大标题 | 22 |
| 二级页标题 | 18 |
| 卡片主标题（地点） | 15 |
| 正文与按钮 | 14 |
| 列表摘要 | 12.5 |
| 时间、说明、标签 | 11–12.5 |

### 5.4 六个界面

**记录列表**：大标题顶栏加右上角导出入口；橙色备份提醒条，可就地导出，可关闭；搜索框；记录卡片为左侧缩略图加右侧地点、时间与照片张数、两行摘要；右下角扩展式悬浮按钮"新建记录"。

**新建记录**：三个字段用填充式输入框，左侧带对应图标；地点下方一行常用地点标签，点一下即填入；描述框下方是整宽语音按钮，识别中变为实心主色；照片区是虚线加号格，拍完的照片以缩略图插在前面。

**记录详情**：地点作为页面主标题，时间在下并带时钟图标；分隔线之后是正文；照片上下排布为大图；底部是等宽的"编辑"与"删除"。

**导出**：分段按钮选择时间范围；下方一张范围卡片，左侧日历图标，右侧范围与"几条记录、几张照片"；再下方一条说明块解释报告形态；底部为实心主按钮"生成报告"。

**报告预览**：灰底衬白色纸张；居中标题加时间范围；逐条记录列出地点、时间、正文，照片按张数并排；底部"保存到文件"与"分享"。

**桌面提醒**：柔和渐变壁纸；顶部为 Android 13 风格通知卡片；中部为小组件，显示"43 天未导出"与上次导出日期；底部为一行应用图标，长按图标弹出"新建记录"菜单。

### 5.5 交互细节

- 点常用地点标签，地点输入框立即填入该地点。
- 点语音按钮进入"正在识别"状态，识别完成后文字落入描述框。
- 添加照片后缩略图插入到照片区最前面。
- 保存后回到列表页，并短暂提示"已保存 1 条记录"。
- 提醒条与通知都可以点右上角关闭。
- 切换导出时间范围时，条数与照片张数联动更新。
- 桌面图标长按直达新建记录，不经过列表页。

## 6. 关键约束

- **纯本地**：不需要账号，不需要服务端，完全离线可用。这既是优势也是约束。
- **数据只存在设备上**：因此"导出全部数据"是必要的备份手段，不是附加功能。
- **数据丢失不可恢复**：卸载 App、换手机、手机丢失都会导致记录消失，需要让用户知情，并在长期未导出时给出提醒。
- **语音能力外置**：依赖系统或第三方输入法，App 内不从零实现语音识别。
- **照片只存在 App 内**：调用系统相机拍摄后，照片保存在 App 自己的目录，不会出现在系统相册。

## 7. 后续迭代方向

- 导出为可编辑表格，便于学校二次汇总
- 故障类型标签与按标签筛选
- 自动定时导出与备份
- 云端同步、多人共享台账
- 设备二维码，扫码直接调出该设备的历史记录

## 8. 决策记录

| 决策 | 结论 | 理由 |
| --- | --- | --- |
| 覆盖平台 | 只做 Android 手机版 | 使用场景集中在手机，第一版不做 iOS |
| 数据存储 | 纯本地，无账号无服务端 | 学校网络不稳，免注册，零成本，数据不出手机 |
| 记录字段 | 时间、地点、问题与解决方法、照片 | 必填项越少，记录越快 |
| 报告格式 | PDF | 便于打印与存档，可直接发微信；长图方案因微信压缩超长图片而放弃 |
| 拍照方式 | 调用系统相机 | 实现简单、兼容性可控；App 内连拍方案因开发量放弃 |
| 提醒方式 | 提示条 + 桌面小组件 + 每月 1 号通知 | 桌面图标变色方案因国产系统支持不稳定被否决 |
| 界面风格 | Material 3，主色为绿色系 | 与安卓原生一致，低学习成本，深浅色自动适配 |

## 9. 待确认事项

- 提示条触发的"长期未导出"阈值，暂定 30 天
- 常用地点是否需要按楼栋分组
- 应用名称与包名
- 最低支持的 Android 版本，暂定 Android 8.0
