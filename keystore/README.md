# 签名文件

`debug.keystore` 是**调试用**签名，口令是 Android 调试签名的通用口令（storePassword 与
keyPassword 均为 `android`，别名为 `androiddebugkey`）。

## 为什么放进版本库

安卓要求：覆盖安装时新包的签名必须与已装的一致，否则只能卸载重装，而卸载会清掉
手机上的全部记录。安卓默认的调试签名保存在用户目录下，会随构建环境变化而重新生成，
已经出现过一次"签名漂移导致更新装不上"的情况，所以这里固定一份并纳入版本库。

## 注意事项

- 这份签名**只能用于开发**。正式发布必须另建发布签名，且发布签名与其口令**绝不能提交**。
- 换成发布签名时，因为签名不同，仍然需要卸载重装，务必先用应用内的「导出备份」留底。
